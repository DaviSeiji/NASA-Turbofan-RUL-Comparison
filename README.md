# NASA-Turbofan-RUL-Comparison

Projeto da UC de Redes Neurais para comparar CNN-LSTM, Transformer, TCN e iTransformer na previsão de vida útil remanescente de motores NASA C-MAPSS (FD001–FD004).

- `data/`: dados brutos e processados.
- `models/`: modelos treinados.
- `results/`: métricas, previsões e gráficos.
- `src/`: código de preparação, treinamento e avaliação.

Os arquivos do projeto serão copiados manualmente para essas pastas.
